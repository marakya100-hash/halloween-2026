Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите ВСЕ файлы рядом с index.html в корень репозитория.
3. В Settings → Pages выберите Deploy from a branch → main → / (root).
4. Откройте опубликованный адрес. Сборка и установка зависимостей не нужны.
Не открывайте index.html через file://: модули JavaScript требуют HTTP/HTTPS.
Для локальной проверки: python -m http.server 8000
